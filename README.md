# BRAXON Frontend

Premium React/Vite frontend for the BRAXON macropad website.

## Local setup

```bash
npm install
cp .env.example .env.local
npm run dev
```

Set `VITE_BRAXON_API_URL` to the deployed backend API origin in production.

## Deploy target

Repository: `git@github.com:BRAXONIND/BRAXON-FRONTEND.git`

No admin credentials, SMTP passwords, API keys, or backend secrets belong in this repository.
